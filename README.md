# Horizon для Android

Нативный клиент Horizon (Rust) + лаунчер-меню + экранное управление. JVM-ядро Mojo не используется.

**Не проверено:** при написании не было cargo/NDK/Android SDK. Rust-патч проверен на совпадение якорей с
`horizon-main`, Java на отсутствие синтаксических ошибок. Ошибки компиляции и запуска лечатся по логам.

## Меню
- **Играть**: пишет аргументы в `game-args.txt` и запускает игру в отдельном процессе (`:game`).
  Если игра упала, меню остаётся живым и показывает предупреждение.
- **Импорт файлов игры (.zip)**: архив с подготовленной папкой `26.3` (внутри `horizon-resources.json`).
  Распаковывается в `Android/data/dev.horizon.mobile/files/.local/horizon-client/26.3/`.
- **Настройки**: дальность прорисовки (2–24, по умолчанию 8), название мира, творческий режим.
- **Логи и ошибки**: Logcat приложения (ловит и нативные падения), `latest.log` игры, краш-репорты,
  `java-crash.txt`; кнопки копирования и отправки. Без ПК и adb.

## Сборка
GitHub Actions: Actions, "Build APK", артефакт `horizon-debug-apk`.

## Игровые файлы
Делаются на ПК шагом prepare из своей копии Minecraft Java. Папку `26.3` из
`~/.local/share/horizon/game-files/horizon-client/` запакуй в zip и импортируй через меню.

## Управление
Левая часть экрана: плавающий стик (до верхнего края: бег). Свободная область: свайп вращает камеру,
тап атакует/ставит, удержание ломает; в меню палец работает как мышь. Кнопки: прыжок, атака, использовать,
присесть, пауза, чат, хотбар, инвентарь, дроп, смена рук, камера. Точка стыка с игрой: `HorizonInput.java`.

## Известные риски
- Нужен телефон с Vulkan 1.1 и arm64.
- Экранная клавиатура (чат, таблички) не подключена; физическая работает через winit.
