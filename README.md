# Horizon для Android

Нативный клиент Horizon (Rust) + оверлей управления в стиле Mojo. Не MojoLauncher: JVM тут не нужна.

**Не проверено:** в песочнице, где это писалось, не было cargo/NDK/javac. Патч проверен только на совпадение
якорей с репозиторием `horizon-main`. Первый запуск CI почти наверняка выдаст ошибки компиляции: кидай лог.

## Сборка (GitHub Actions)
1. Запушь этот проект в репозиторий.
2. Вкладка Actions, "Build APK", Run workflow (поле ref можно оставить `main`).
3. Готовый APK: Artifacts, `horizon-debug-apk`.

## Игровые файлы
Клиент берёт ресурсы из `<files>/.local/horizon-client/26.3/` (внутри `horizon-resources.json`), где
`<files>` это `Android/data/dev.horizon.mobile/files/`. Их делает шаг prepare на ПК (нужна своя копия
Minecraft Java): папку `26.3` из `~/.local/share/horizon/game-files/horizon-client/` скопируй туда
(`adb push` или файловый менеджер; на Android 11+ в `Android/data` без adb/Shizuku не записать).

## Управление
Левая часть экрана: плавающий стик (до верхнего края: бег). Свободная область: свайп вращает камеру,
тап атакует/ставит, удержание ломает; в меню палец работает как мышь. Кнопки: прыжок, атака, использовать,
присесть, пауза, чат, хотбар, инвентарь, дроп, смена рук, камера.
Стык с игрой один: `HorizonInput.java`. Родные классы кастомных раскладок Mojo подключаются к нему.

## Известные риски
- Правки `linux` на `linux|android` (флаг `--linux-cfg`) могут потянуть недостающие API.
- Нужен телефон с Vulkan 1.1 и arm64.
- Экранная клавиатура (чат, таблички) не подключена; физическая работает через winit.
